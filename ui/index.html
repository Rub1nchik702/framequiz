    Сверка сложности с AMQ

    В AMQ Song List UI откройте Song List → Export. Выберите сохранённый JSON здесь. Студия сверит записи по аниме, песне, исполнителю и номеру OP или ED и запомнит проценты для следующих загрузок. Для остальных песен показывается процент из AnisongDB.

    Импорт папки

    Мои треки

    Каталог.

    Все аниме от самых популярных. Справа фильтры по жанру, годам и сложности угадывания (по данным Anime Music Quiz). Клик по аниме показывает его опенинги и эндинги.

    Фильтры

    Аниме, у которых есть опенинги или эндинги этой сложности. Сначала самый высокий рейтинг.

    Песни

    Выберите аниме слева. Здесь появятся его опенинги и эндинги с номерами.

    Раунды.

    Перетащите тайтл из библиотеки в раунд или нажмите «В раунд» на карточке. Каждый раунд получает шаблон: угадывание с таймером, обложка тайтла и видео с пиковым моментом.

    Библиотека

    Дизайн.

    Опишите, как должны выглядеть интро, экран угадывания (таймер, полоса времени, место под картинку), ответ и аутро. Claude соберёт шаблон, а вы сразу увидите сцены справа.

    Ключ Claude API

    Ключ с console.anthropic.com. Он хранится только в этом приложении на вашем компьютере. Запрос с вашим описанием и текущим шаблоном уходит только в Anthropic.

    Вставить ответ Claude вручную

    Нажмите «Скопировать промт», отправьте его Claude в любом чате и вставьте сюда его JSON-ответ.

    Сайты и референсы
    
              
              
    
              
    
              
    Импорт с сайта
    
              
    
                Выберите тематику в форме вопроса, вставьте прямую HTTPS-ссылку на ленту или файл и нажмите «Прочитать источник».
              
    Какую ссылку вставить?
              
    Для идей скопируйте адрес RSS или Atom с сайта. Студия покажет до 20 публикаций. Нажмите «Взять за основу», затем впишите вопрос и ответ.
    
              
    Для готовых вопросов дайте прямую ссылку на доступный без входа JSON-файл в UTF-8. При открытии адреса должен быть виден массив, например
    
              
    [{"question":"Who is Luffy’s brother?","answer":"Ace","difficulty":"easy"}]
    
              
    Допустимые уровни — easy, medium и hard. За один раз добавляется до 200 новых вопросов выбранной тематики. Музыка загружается отдельно в фонотеке.
